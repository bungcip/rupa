## Implementation Summary

- **IR**: added `LayerDefinition::center()` and
  `LayerInstance::local_to_parent_transform()`. The mapping is
  `translate(x,y) * translate(cx,cy) * instance.transform * translate(-cx,-cy)`;
  local `(0,0)` maps to the instance position and scale/rotation pivot on
  layer bounds center.
- **Renderer**: uses the shared IR mapping; duplicate private matrix helper
  removed. Child shape transforms are composed in local space before the
  instance parent matrix.
- **Tests**: IR mapping tests for origin, center, scale pivot, and definition
  immutability; renderer test for child transform + instance composition; CLI
  test for a non-origin local child placement.
- **Decision** `docs/decisions/DECISION-018.md` records local coordinate
  conventions and the reusable parent-space mapping.
