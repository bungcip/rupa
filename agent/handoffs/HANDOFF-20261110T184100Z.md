## Implementation Summary

- **AST**: added `Transform { rotate, scale, opacity, span }` and `Scale`;
  all nine primitive nodes carry `transform: Option<Transform>`.
- **Parser**: accepts `rotate <deg>`, uniform `scale <factor>`, non-uniform
  `scale <sx> x <sy>`, and dimensionless `opacity` on every primitive.
- **Validation**: added `S014` for non-degree rotation units, non-positive or
  non-finite scale, and opacity outside `0.0..=1.0`.
- **Lowering**: composes `rotate * scale` and carries opacity; missing
  properties default to identity/1.0. Position remains geometry, not matrix.
- **Renderer**: existing center-pivot transform handling is used; tests added
  for composed transform and opacity affecting both fill and stroke.
- **Decision** `docs/decisions/DECISION-014.md` records syntax, composition
  order, units, and validation.
- **Task document** `agent/tasks/TASK-017.md` was missing and created before
  implementation.
