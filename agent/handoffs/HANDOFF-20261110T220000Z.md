# Handoff — TASK-027: Picture placement and fit modes

**Date**: 2026-11-10T22:00:00Z
**Task**: TASK-027
**Status**: Completed and verified

## Implementation Summary

- Syntax: `picture "<path>"` with `at` (header or property line), optional
  `size`, `fit contain|cover|fill|none`, and rotate/scale/opacity.
- AST/IR: new `Picture`/`FitMode` AST nodes and `PictureNode` with path, frame,
  fit, transform, and opacity. Pictures order at z-index 0 with shapes.
- Validation: missing `at` is S003, empty path is the new S022, frame sizes use
  the existing non-positive/non-pixel dimension diagnostics, transforms are
  validated by the shared transform rules.
- Rendering: each picture is clipped to its transformed frame intersected with
  enclosing layer masks. `contain`, `cover`, `fill`, and `none` follow
  DECISION-024.
- Resources: `render_document_with_resources` loads through `ResourceStore`;
  plain `render_document` reports `MissingResource`. The CLI roots the store at
  the input document's directory.
- Decision recorded in `docs/decisions/DECISION-024.md`.
