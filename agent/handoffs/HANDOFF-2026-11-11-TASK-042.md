# Handoff — TASK-042: Function grammar and basics

## Completed Work
- Added `Function` AST and `functions` field on `Document`.
- Parser supports `fn name(params)` with indented or same-line `return`.
- Top-level and document-level function declarations are supported.
- Validation collects functions, checks duplicate names/parameters, and threads
  them through expression evaluation.
- Lowering evaluates function calls in `let` and repeat counts.
- Recursion is protected by a call-depth limit.
