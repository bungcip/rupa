### Follow-up clarifications added in the same revision
- §2.3 defaults table now lists every new default explicitly: canvas
  `256px x 256px`, transparent background, layer size = document canvas, group
  size = automatic bounding box, clipping rules, and `z-index` omitted = `0`
  with stable source order.
- **Group origin vs automatic size resolved**: the local origin is always the
  authored `(0px, 0px)`; the automatic bounding box is a measured extent in
  local coordinates (reporting + rotate/scale origin) and never re-anchors
  content; `place ... at` positions the local origin; an explicit `size` is a
  viewport anchored at the origin and clips negative-coordinate content.
  Recorded in §6.2, §6.6, §11, §17 and in DECISION-032's addendum.
- `z-index` default is `0`; ties keep source order and the implicit root plane
  counts as declared first, so top-level content sits behind a default-index
  layer (negative z-index to go behind).
- Layer background `fill` shorthand stated in §3/§6.4 and `fill` at file top
  level rejected (§23.2 test list).
- Group and layer names are separate namespaces (§4.1).
- New §6.9 complete worked example: one `group "Cloud"` with three
  `place`ments plus `layer "Background"` (z-index 0, background `fill`) and
  `layer "Foreground"` (z-index 10) on a 1200x800 transparent canvas.
- §23.5 benchmark task 3 now says "reuse one group definition".

The user confirmed mid-run that the `document` wrapper stays removed; the
example sketch in the request that used it was treated as accidental.
