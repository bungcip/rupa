## Implementation Summary

- **IR**: added `rupa_ir::GraphicsDocument` (dimensions, optional background,
  `PaintStore`, ordered `ShapeNode`s). The renderer re-exports it as
  `RenderDocument`.
- **Compiler**:
  - `parse_source` → `ParsedSource { document, diagnostics }`
  - `compile_source` → `CompiledSource { document, graphics, diagnostics }`
  - `lower_document` lowers validated AST to `GraphicsDocument`
  - validation reuses the shared parse API
  - lowering rounds canvas dimensions to nearest pixel and reports `C008`
    for canvases too large for `u32`
  - `fill none` allocates no paint
- **CLI**:
  - `src/main.rs` (clap structure), `src/commands.rs`, `src/diagnostics.rs`
  - `rupa check <input>`: exit 0/1, source-context diagnostics to stderr,
    stdout empty on success
  - `rupa render <input> --output <file.png>`: required `--output` (exit 1
    manual error, not clap exit 2), compile → render → PNG; no file on failure
  - `--help` works for root, check, and render
  - non-PNG output paths rejected via `C006`
  - document `export` is validated but `--output` overrides it
- **Tests**: 12 CLI integration tests, plus compiler lowering/compile tests
  and IR document tests.
- **Decision** `docs/decisions/DECISION-007.md` records the API/CLI contract.
