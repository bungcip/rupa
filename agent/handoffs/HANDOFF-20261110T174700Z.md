## Implementation Summary

- **`rupa-image`** (`crates/rupa-image/src/encode.rs`)
  - Added `png = "0.18"`.
  - `encode_rgba_png(pixels, width, height, path)` and
    `encode_rgba_png_to_writer`: 8-bit RGBA PNG with an sRGB chunk
    (perceptual intent).
  - `encode_png(&ImageBuffer, path)` convenience.
  - `unpremultiply_rgba`: premultiplied → straight alpha with clamping and
    transparent-pixel normalization.
  - `validate_rgba_buffer`: rejects zero dimensions and wrong buffer length
    before creating a file.
- **`rupa-renderer`** (`crates/rupa-renderer/src/png.rs`)
  - `encode_png(pixels, width, height, path)` unpremultiplies renderer output
    then writes a PNG.
  - `encode_render_output(&RenderOutput, path)` convenience.
  - `PngError` wraps `rupa_image::EncodeError`.
- **Tests**: 7 image tests (dimensions/pixels, srgb chunk, invalid input,
  unpremultiply) and 5 renderer PNG tests (minimal 200×100 document, exact
  pixels, transparent background, semi-transparent conversion, validation).
- **Decision** `docs/decisions/DECISION-006.md` records the PNG color/alpha
  contract.
