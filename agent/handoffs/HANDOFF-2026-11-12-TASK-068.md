# Handoff — TASK-068: Optional document size and background defaults

## Task ID
TASK-068 (Milestone 10)

## Completed Work
- `size` is optional end to end. `rupa-ir` now exposes
  `DEFAULT_CANVAS_WIDTH`/`DEFAULT_CANVAS_HEIGHT` (both `256`), re-exported from
  the crate root.
- `DocumentValidator::validate_size` no longer reports a missing `size`; it
  validates only an explicit declaration (positive, finite, pixel units).
- `lower_document` applies the 256x256 default when `size` is absent and always
  writes the effective canvas into `graphics.root` bounds, so the implicit root
  layer matches the defaulted canvas.
- `background` stays optional: an omitted declaration lowers to `None`, which
  the renderer already treats as a transparent canvas.
- `C005` is retained as a stable diagnostic code but marked legacy and never
  emitted (`rupa-syntax/src/diagnostic.rs`).
- Renderer needed no change; it already receives concrete canvas dimensions.
