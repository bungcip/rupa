# Handoff — TASK-058: Implicit root layer

## Task ID

TASK-058 (Milestone 9 — Document Model & Root Layer Refactor)

## Completed Work

- Added implicit `GraphicsDocument.root: LayerDefinition` with:
  - reserved name `root`
  - bounds equal to the document canvas
  - vector mode, `clip: false`
  - top-level primitives and placements as its children
- Moved root children storage from `GraphicsDocument.children` to
  `root.children`; added `children()`, `children_mut()`, and root-layer-aware
  accessors.
- Compiler lowering writes top-level content into the root layer and keeps
  explicit layers in `GraphicsDocument.layers`.
- Renderer consumes `document.root.children`.
- Added `S029` and reject explicit `layer "root"` definitions. Layer names remain
  case-sensitive, so `"Root"` is allowed.
- `rupa inspect` now serializes compiled graphics IR, exposing the implicit root
  layer and its children.
- Added IR/compiler/CLI tests for root metadata, ownership, reserved name, and
  inspect output.
