## Implementation Summary

- **AST**: added `LayerDefinition { name, size, children, span }`; `Document`
  now stores `layers: Vec<LayerDefinition>` separately from root `children`.
- **Parser**: handles `layer "<name>"` blocks with `size` and shape children;
  shape dispatch was factored into `parse_child_shape` and reused by document
  and layer blocks.
- **Validation**: new `rupa-compiler/src/layer.rs`:
  - `S015` missing layer size
  - `S016` duplicate layer name (case-sensitive)
  - `S017` non-positive/non-finite layer size
  - `S018` empty layer name
  - `S007` non-pixel layer size
  - layer child shapes validated through the normal shape/paint path
- **Lowering**: definitions are intentionally ignored until instances exist;
  layer-only documents lower to an empty root scene.
- **Decision** `docs/decisions/DECISION-016.md` records storage, validation,
  and non-rendering semantics.
- **Task document** `agent/tasks/TASK-019.md` was missing and created before
  implementation.
