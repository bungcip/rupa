# Handoff — TASK-022: Z-index stable sorting

**Date**: 2026-11-10T19:25:00Z
**Task**: TASK-022
**Status**: Completed and verified

## Implementation Summary

- **IR**: `GraphicsDocument` now stores one ordered root child list,
  `children: Vec<RootChild>` (`Shape(ShapeNode)` or `Instance(LayerInstance)`),
  replacing separate root `shapes`/`instances` vectors. `push_shape` and
  `push_instance` append in source order; `shapes()`/`instances()` return
  source-ordered filtered views.
- **Ordering**: `RootChild::z_index()` returns the instance z-index or `0` for
  direct shapes. `stable_z_index_order` sorts ascending with a stable sort, so
  equal z-index keeps source order. `GraphicsDocument::children_in_render_order`
  exposes it.
- **Lowering**: root children are pushed in source order, so shapes and
  instances interleave instead of all shapes preceding all instances.
- **Renderer**: `render_document` iterates `children_in_render_order`, drawing
  shapes with identity parent and instances with their local-to-parent
  transform and opacity. Existing transform/opacity behavior is unchanged.
- **Decision**: `docs/decisions/DECISION-019.md` records ordering semantics,
  the merged representation, and the `z-index 0` default for absent values and
  direct shapes.
- **Task document**: `agent/tasks/TASK-022.md` created before implementation.
