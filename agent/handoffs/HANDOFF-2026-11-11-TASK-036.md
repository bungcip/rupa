# Handoff — TASK-036: Variable declarations and scoping

## Completed Work
- Added `Variable` and `Expression` AST nodes and `DocumentChild::Let`.
- Parser handles `let name = value` in document and layer blocks.
- Values may be numbers, dimensions, strings, booleans, identifiers, or
  coordinate pairs.
- Duplicate variable names in one block are reported as `S024`.
- Lowering ignores declarations.
- Updated task/backlog/status/current state.
