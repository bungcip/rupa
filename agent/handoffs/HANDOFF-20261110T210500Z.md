## Implementation Summary

- `rupa_image::decode_image(path)` reads a file and decodes it; errors name the
  path.
- `rupa_image::decode_png(bytes)` decodes PNG bytes into canonical 8-bit
  straight-alpha RGBA8, expanding grayscale, gray+alpha, RGB, indexed, and RGBA
  inputs and stripping 16-bit samples to their high byte.
- Format detection uses the PNG signature rather than the extension.
- `ImageError` carries the resource path; `ImageErrorKind` is the
  path-independent failure reason (`UnsupportedFormat`, `Decoding`,
  `InvalidDimensions`).
- `ImageBuffer` validates dimensions/buffer length and offers bounds-checked
  `pixel()`.
- `ResourceStore` resolves references against a base directory (absolute paths
  unchanged), decodes each resolved path once, and exposes sorted cache
  inspection.
- Conventions recorded in `docs/decisions/DECISION-023.md`.

## Known Issues / Notes

- Only PNG input; other formats produce `UnsupportedFormat`.
- No gamma/color-space conversion is applied, keeping output deterministic.
- Straight-alpha buffers must be premultiplied before compositing.
- `ResourceStore` does not canonicalize paths.
- `ResourceStore` is not yet wired into the CLI or IR; TASK-027 introduces the
  `picture` node and will own that integration.
