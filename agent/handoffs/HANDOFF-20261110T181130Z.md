**Date**: 2026-11-10T18:11:30Z

**Status**: Completed and verified

## Implementation Summary

- **AST** (`rupa-syntax`): added `Polygon { points: Option<Vec<Position>>,
  fill, span }` and `DocumentChild::Polygon`.
- **Parser**: parses `polygon` with a nested `points` block; each entry is a
  parenthesized `(x, y)`. `points` and `fill` may appear in either order.
- **Diagnostics**: added stable codes:
  - `S008` missing `points` block
  - `S009` fewer than three points
  - reused `S006` missing fill and `S007` non-pixel coordinates
- **Validation**: point count, pixel-unit coordinates, and fill presence.
- **IR**: `Point { x, y }` and `Polygon { points }`.
- **Lowering**: preserves point order, resolves fill through the paint arena.
- **Renderer**: closed path, nonzero winding, transform origin at the
  bounding-box center.
- **Decision** `docs/decisions/DECISION-010.md` records closure, fill rule,
  coordinate scope, and validation.
- **Task document** `agent/tasks/TASK-013.md` was missing and was created from
  the backlog and specification before implementation.
