## Completed Work

- `FileId` is now `u8`; `FileId::new` accepts only `0..=255`.
- Source files are limited to `16,777,215` bytes (16 MiB - 1). Oversized files
  report `L010` and are not scanned.
- `Position` stores only a byte offset (`u32`).
- `Location` packs the file id in the high 8 bits and a 24-bit offset in the
  low bits; `Span` is an 8-byte pair of locations.
- `LineIndex` derives one-based line and Unicode-scalar column from a byte
  offset. CLI/wasm JSON and human diagnostic rendering use it; the formatter
  uses it for comment indentation.
- `DiagnosticBag::sort` orders by packed file id and byte offset.
- Specification §2.6 and DECISION-043 document the limits and API changes.
- Size and allocation guardrails and new limit/packing tests were added.
