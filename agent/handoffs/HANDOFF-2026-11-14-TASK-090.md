# HANDOFF-2026-11-14-TASK-090

## Completed work

- `render_diagnostic` now quotes the primary span from the source:
  - same-line span: one line, caret from start to end column, label on the
    caret;
  - multi-line span: up to three lines, first line underlined from the start
    column, middle lines fully underlined, final line underlined to the end
    column;
  - longer spans stop after three source lines.
- The first caret run carries `Diagnostic.message` as its label. The header keeps
  the full message, matching conventional compiler output.
- Caret width now uses character columns instead of byte offsets, so non-ASCII
  snippets stay aligned.
- Out-of-range spans still print `(source line unavailable)`.
- Added two syntax unit tests (multiline rendering and three-line cap), updated
  the existing single-line test, and added a `rupa check` integration test that
  asserts the quoted line, caret, and label.
- Spec §22.3 and `crates/rupa-cli/src/diagnostics.rs` document the output.
