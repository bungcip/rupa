# Handoff — TASK-020: Layer instance placement and transforms

**Date**: 2026-11-10T19:03:00Z
**Task**: TASK-020
**Status**: Completed and verified

## Implementation Summary

- **AST/parser**: added `LayerInstance` and `DocumentChild::Place`.
  `place "<name>" at (x, y)` blocks support `rotate`, `scale`, `opacity`, and
  `z-index`. Missing position is retained for `S003`.
- **Validation**: `S019` unknown layer, `S020` non-integer z-index; instance
  transforms reuse `S014`, empty names `S018`, missing position `S003`.
  References resolve independent of declaration order.
- **IR**: `GraphicsDocument` now stores `LayerDefinition` and `LayerInstance`
  values separately from root shapes, sharing the paint store.
- **Lowering**: lowers definitions and instances, including forward
  references; definitions are not flattened into root shapes.
- **Renderer**: renders multiple instances independently, applies instance
  transforms around layer bounds center, and multiplies instance opacity into
  child opacity.
- **Decision** `docs/decisions/DECISION-017.md` records placement/transform
  conventions and the temporary source-order limitation.
- **Task document** `agent/tasks/TASK-020.md` was missing and created before
  implementation.
