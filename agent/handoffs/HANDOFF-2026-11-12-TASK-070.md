# Handoff — TASK-070: Group definitions and group-only placement

## Task ID
TASK-070 (Milestone 10)

## Completed Work
- **Syntax**: `group` is a keyword; `ast::Document.groups: Vec<GroupDefinition>`
  and `GroupDefinition { name, size: Option<Size>, children, span }` were
  added. `ast::LayerDefinition` now also carries `z-index`, `opacity`, and
  `blend`. The AST placement node is `GroupInstance` (`Place(GroupInstance)`).
- **Parser**: top-level `parse_group` accepts `size`, nested `place`, `let`,
  `repeat`, and primitives. `place` bodies are now optional
  (`has_indent()` helper), so `place "Dot" at (0px, 0px)` on its own parses
  instead of emitting `P001`.
- **Validation**: new `crates/rupa-compiler/src/group.rs`
  (`GroupValidator::{validate_groups, validate_placements, validate_instance,
  validate_cycles}`) reports `S030` duplicate group name, `S031` invalid group
  name, `S032` invalid group size, `S033` unknown group (with a did-you-mean
  suggestion), `S034` place targets a layer, and `S035` recursive group
  reference. `layer.rs` now validates layer definitions and planes only;
  `S019`/`S021` stay defined as legacy.
- **IR**: `GraphicsDocument.groups`, `Bounds`, `GroupDefinition { name,
  bounds, clip, children }`, `GroupInstance { group, x, y, transform,
  opacity, z_index, blend_mode }`, `LayerPlane { layer, z_index, opacity,
  blend_mode }`, and `CompositionChild::Plane`. `GroupInstance::
  local_to_parent_transform` pivots on `group.bounds.center()`. New
  `composition_bounds(children, groups)` measures automatic bounds (stroke
  widths ignored, text `0.6 * size * chars` × `size`, pictures use their frame,
  raster clear excluded).
- **Lowering**: root lowering appends one `Plane` per layer and then lowers
  groups in two passes so measured bounds can reference later groups.
- **Renderer**: `render_composite` is shared by group instances and layer
  planes. Group instances clip only when the group was declared with a size and
  render offscreen only for non-normal blend modes; planes keep the existing
  raster/blend/filter offscreen path at the document origin.
- **Fixtures**: `examples/layers.rupa`, `examples/paints.rupa`,
  `examples/raster.rupa`, `benchmarks/solutions/{poster-layers,reuse-layer}.rupa`,
  `examples/invalid/unknown_layer.rupa` → `unknown_group.rupa`, benchmark
  prompts, CLI/compiler/parser/renderer inline sources, and
  `docs/language-reference.json` were migrated to the group model. Layers that
  used to be placed are now canvas-sized single-use planes.
