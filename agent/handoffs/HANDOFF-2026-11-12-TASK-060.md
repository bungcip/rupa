# Handoff — TASK-060: Unify shape validation and lowering

## Task ID

TASK-060 (Milestone 9 — Document Model & Root Layer Refactor)

## Completed Work

- `ShapeValidator` now shares `validate_required_position`; rectangle, ellipse,
  square, triangle, and picture reuse `validate_size_property`.
- Compiler validation validates fill/stroke paint through shared
  `validate_fill_color` and `validate_paint_fields` helpers.
- Lowering now has a shared `ShapeAppearance` + `lower_shape_appearance` path for:
  - fill
  - optional or required stroke
  - transform
  - opacity
- Each shape lowering function now supplies only its geometry plus the
  require-stroke flag.
- `lower_fill` accepts `Option<&Fill>` so callers no longer repeat conditional
  glue.
- Geometry-specific missing-property diagnostics remain explicit and unchanged.
- Added table tests for invalid fill and stroke colors across every applicable
  primitive.
