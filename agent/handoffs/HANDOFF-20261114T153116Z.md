# Handoff — TASK-100 (Migrate AST string fields)

- **Task**: TASK-100
- **Milestone**: M16 — Interned identifiers
- **Status**: Complete
- **Date**: 2026-11-14

## Completed Work

- Migrated all AST identifier/name fields to `IStr`:
  `GroupDefinition.name`, `LayerDefinition.name/blend`,
  `GroupInstance.name/blend`, `LayerEffect.kind`, `Text.font`,
  `Function.name/params`, `Variable.name`, `Repeat.index`,
  `Color::Named/Hex`, `PatternFill.kind`, `Expression::Identifier`,
  `Expression::Call.name`.
- Migrated unique payloads to `Box<str>`: `Text.text`, `Picture.path`,
  `LayerEffect.resource`, `Expression::String`, `Value::String`.
- Removed duplicate `Text.content`; `Text` now stores and serializes one
  content string.
- Parser constructs `IStr` and `Box<str>` directly from tokens; added
  `expect_istr` and changed `expect_string` to return `Box<str>`.
- Compiler evaluation scopes/function tables now key on `IStr`; IR remains
  `String` with one conversion at the lowering boundary.
- Added `tests/ast_strings.rs` proving single text content, plain-string name
  JSON, and `Text` serde roundtrip.
- Tightened AST size and allocation guardrails; recorded results in
  DECISION-042.
