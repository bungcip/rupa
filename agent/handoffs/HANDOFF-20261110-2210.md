## Key Fixes Applied

1. **Accurate source spans**: Captures start position before scanning each token using `span_from_start()` helper
2. **Blank/comment-only lines**: Properly ignored for indentation tracking (no spurious `Indent`/`Dedent`)
3. **Tab rejection**: Rejected everywhere (not just in indentation) with error code L002
4. **Operator tokens**: `=` emits `Assign`, `==` emits `Eq` (fixed from scaffolded bug where `=` emitted `Colon`)
5. **Percent unit**: Added `Unit::Percent` support for `%` suffix on numbers
6. **Error diagnostics**: Added comprehensive error codes:
   - L001: Invalid indentation (not multiple of 4, or increase > 1 level)
   - L002: Tab character found
   - L003: Unterminated string literal
   - L007: Invalid character
   - L008: Invalid escape sequence
   - L009: Unknown unit suffix
