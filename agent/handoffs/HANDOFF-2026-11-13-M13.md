# Handoff — Milestone 13 (inline primitive properties)

*Date: 2026-11-13*

## What shipped

A drawing primitive may now carry its properties on its own line:

```rupa
size 320px x 200px
background white

rectangle at (10px, 40px) size 80px x 40px fill red
circle center at (150px, 50px) radius 30px fill blue
```

Indentation now means "this block continues the previous primitive". Inline
lists end at the end of the line, so a following sibling primitive starts a new
shape. Inline followed by an indented block is also valid and continues the same
primitive. `layer`, `group`, `repeat`, and `fn` still require an indented body,
and block-valued properties (`fill gradient`, `fill pattern`, `points`, path
`control`) still need their own block.

`rupa fmt` expands inline properties into the canonical one-property-per-line
form and preserves `//` comments, which it previously deleted. Formatting is
idempotent.

## Gotchas for the next agent

- `examples/` sources must equal their `rupa fmt` output — the inline showcase
  therefore lives at `playground/examples/inline-shapes.rupa` only, and
  `examples/raster.rupa` was migrated from `brush size 8px` to the expanded
  block form. `playground/examples/raster.rupa` still uses the inline spelling
  on purpose.
- The formatter flushes a comment when it reaches the next token; a flushed
  comment already ends its line, so the next `Newline` token must be suppressed,
  and the flag must be cleared by the following real token. Getting that wrong
  produced lines like `rectangle at (10px, 10px)    size 80px x 40px`.
- Comment-only lines are skipped by `handle_indentation`; if a future change
  reworks that path, re-check `rupa fmt` keeps standalone comments.
- Run cargo with `CARGO_INCREMENTAL=0` on this UNC workspace, and never retry a
  test run while a stale `target/debug/deps/*.exe` still holds a lock — kill the
  stray test process instead (it shows up as `LNK1104`).
