## Implementation Summary

- **Transform** (`crates/rupa-geometry/src/transform.rs`)
  - Documented column-vector 3x2 matrix convention and `multiply(self, other)`
    order (`other` first).
  - Corrected rotation direction: positive angles rotate clockwise on screen
    (quarter turn maps `(1,0)` to `(0,1)`).
  - Added `transform_point`, `rotate_about`, `scale_about`, and 9 tests.
- **Renderer** (`crates/rupa-renderer/src/vector.rs`)
  - Added `tiny-skia = "0.12"`.
  - `RenderDocument { width, height, background, paints, shapes }` →
    `RenderOutput { width, height, premultiplied RGBA8 pixels }`.
  - `render_document` clears the background (transparent default), then draws
    shapes in source order.
  - Rectangle/circle geometry converted with `tiny-skia` `PathBuilder`.
  - Solid paints resolved through `PaintStore`; opacity multiplied into alpha;
    tiny-skia handles premultiplied compositing.
  - Shape transforms pivot on the rectangle/circle geometric center.
  - Errors: invalid dimensions, degenerate geometry, missing paint ID.
  - 18 renderer tests cover position/size, colors, transforms, opacity,
    ordering, transparent backgrounds, premultiplied alpha, and errors.
- **Decision** `docs/decisions/DECISION-005.md` records transform semantics,
  pivot convention, renderer boundary, and pixel format.
