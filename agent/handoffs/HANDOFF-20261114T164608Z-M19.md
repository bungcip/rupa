# HANDOFF-20261114T164608Z — M19 lean interner

## Completed Work

- Evaluated backend options for removing `ustr`'s fixed cold-start cost:
  patched `ustr`, `Arc<str>`, indexed handles, and a lean pointer interner.
- Replaced `ustr` with a lean pointer interner in
  `crates/rupa-syntax/src/intern.rs`. `IStr` is now `&'static Entry` (8 bytes
  native, 4 bytes wasm32); entries hold `Box<str>` plus a precomputed hash and
  are leaked for process lifetime.
- Removed `Borrow<str>` because `IStr` hashes by its precomputed entry hash, not
  by `str` content. `Deref`, `AsRef<str>`, `Display`, `Debug`, and serde are
  unchanged.
- Removed `ustr` from the workspace and `rupa-syntax` dependencies; `Cargo.lock`
  no longer contains `ustr`, `ahash`, `parking_lot`, `lazy_static`, or
  `byteorder` for this path.
- Added a cross-thread canonicalization test.
- Recorded DECISION-044 and updated TASK-105, ROADMAP, BACKLOG, STATUS, and
  CURRENT.

## Known Issues

- Interned unique identifiers are still retained for process lifetime, by
  design and matching the previous `IStr` contract.
- `Borrow<str>` is no longer implemented for `IStr`.
- The interner uses a fixed-key `DefaultHasher`; identifiers from adversarial
  sources are not protected against crafted collisions. This is outside the
  compiler's threat model and matches the prior local-only usage.
- Benchmark scripts, baseline binaries, and temporary test sources remain under
  ignored `target/interner-eval/`; cleanup requires user authorization.
