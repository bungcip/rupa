# HANDOFF-2026-11-14-TASK-088

## Completed work

- Added `crates/rupa-syntax/src/metadata.rs` as the single keyword table.
  A macro generates the lexer lookup (`keyword_token`), `KNOWN_KEYWORDS`
  (`ALL_KEYWORDS`), highlighter classes, and documented/removed status. Units
  and primitive property lists live here too.
- `crates/rupa-compiler/src/metadata.rs` assembles `metadata_json()` from the
  syntax tables and `paint::NAMED_COLORS`.
- `rupa metadata` prints canonical JSON, `--output` writes it, and
  `--reference FILE` merges canonical keys into the existing reference while
  preserving hand-authored fields.
- `rupa-wasm` exports `metadata_json()` and C ABI `rupa_metadata()`. The payload
  uses the same `[total][meta_len][meta][body]` header as `rupa_format`.
- `playground/app.js` builds `WORD_CLASSES` and the unit regex from
  `rupa_metadata()` at load time. If metadata has not loaded yet, source still
  renders highlighted as plain text; it repaints immediately after setup.
- `docs/language-reference.json` now carries canonical `keyword_classes`,
  `keywords`, `named_colors`, `units`, and `primitives`. Its `text` primitive no
  longer lists the non-existent `content` property.
- Added TASK-088, DECISION-037, wasm/CLI tests, and README updates.
