- New crate `crates/rupa-wasm` (`cdylib` + `rlib`), added to the workspace:
  - `src/lib.rs`: `render_source(&str) -> Frame { meta, png }`, `encode_frame`,

    `renderError`); `FRAME_HEADER_BYTES`.

  diagnostics with positions, determinism, golden parity, frame layout, `R001`)
  and 3 ABI tests in `abi.rs`.
