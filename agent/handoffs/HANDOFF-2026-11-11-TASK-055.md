# Handoff — TASK-055: LLM benchmark suite

## Task ID

TASK-055 (Milestone 8 — LLM Authoring Experience)

## Implementation Summary

- Added `benchmarks/tasks.json` with eight tasks covering every category in
  specification §23.5:
  basic shape, poster layers, layer reuse, procedural pattern,
  paths/gradients/text, modify existing source, repair invalid source, and
  reproduce a reference composition.
- Added canonical solutions in `benchmarks/solutions/` and starters in
  `benchmarks/starters/`. The repair starter is verified to still emit `C004`.
- Added `rupa bench` (`crates/rupa-cli/src/benchmark.rs`) with offline candidate
  evaluation. No model provider is called.
  - Candidates may be `<candidates>/<task-id>.rupa` or ordered
    `<candidates>/<task-id>/attempt-*.rupa`.
  - Reports per-attempt and aggregate metrics: first/final compilation,
    rendering success, syntax/semantic error rates, repair iterations, visual
    similarity, exact pixel-match ratio, token count, source bytes/lines.
  - Failed candidates do not fail the harness; they score zero where
    appropriate.
  - Unattempted tasks are reported without rendering their solutions.
- Added `benchmarks/README.md` documenting layout, task kinds, metric
  definitions, and usage.
- Added `crates/rupa-cli/tests/benchmark.rs` covering perfect reference runs,
  repair iterations, failed candidates, and unattempted tasks.
- Updated the stale `inspect` CLI help text while touching the command enum.
