# Handoff — TASK-012: Ellipse, square, and triangle primitives

**Date**: 2026-11-10T18:06:30Z
**Task**: TASK-012
**Status**: Completed and verified

## Implementation Summary

- **AST** (`rupa-syntax`): added `Ellipse`, `Square`, and `Triangle` nodes and
  `DocumentChild` variants. Required properties are `Option` so missing values
  are semantic errors.
- **Parser**: added `ellipse center at`, `square at`, and `triangle at`.
  Square accepts a single `size <side>`; ellipse/triangle accept
  `size <width> x <height>`.
- **Validation** (`ShapeValidator`): new validators reuse stable codes:
  - `S003` missing position/center
  - `S004` missing size
  - `S006` missing fill
  - `S001` non-positive dimension
  - `S007` non-pixel dimension
- **IR**: added `Ellipse { cx, cy, width, height }` and `Triangle { x, y,
  width, height }`; squares lower to rectangle geometry.
- **Lowering**: AST→IR for all three primitives, preserving source order and
  resolving fills through the paint store.
- **Renderer**: ellipse via `tiny-skia` oval; triangle as an apex-up isosceles
  path inside the bounding box; transform origins at ellipse center and
  triangle bounding-box center.
- **Decision** `docs/decisions/DECISION-009.md` records geometry conventions
  and the triangle orientation interpretation.
- **Task document** `agent/tasks/TASK-012.md` was missing and was created from
  the roadmap/backlog and specification before implementation.
