## Completed Work

- TASK-103 changed `FileId` to `u8`, limited source files to 16,777,215 bytes
  (16 MiB - 1), made `Position` offset-only, packed file id + 24-bit offset into
  `Location`, and reduced `Span` to 8 bytes.
- `LineIndex` now derives one-based line/Unicode-scalar column at diagnostic
  boundaries. CLI/wasm JSON and formatter comment indentation use it.
- Oversized source reports `L010` without scanning; `DiagnosticBag::sort` orders
  by file id and byte offset.
- Specification §2.6 and DECISION-043 record the limits and API change.
- TASK-104 re-ran every gate and verified layout, performance, wasm size,
  diagnostic JSON, inspect JSON, and golden PNGs.
