## Completed Work

- Verified all AST nodes already carry `Span` (file/line/column/offset) — completed as part of TASK-003 and committed at the start of this session (f3744c6).
- Implemented diagnostic pretty-printing with source context:
  - `render_diagnostic(path, source, diag)` and `render_diagnostics(path, source, bag)` produce rustc-style output: `error[L006]: message`, `--> path:line:col`, source line, caret run under the span, optional `= help:` line.
- Implemented did-you-mean suggestions:
  - `did_you_mean(input)` / `did_you_mean_from(input, candidates)` using Levenshtein distance with a length-proportional threshold (clamped 1..3) and deterministic alphabetical tie-breaking.
  - `KNOWN_KEYWORDS` list of all Rupa keywords.
  - `Diagnostic::with_suggestion` appends "did you mean `X`?" to existing help.
  - Parser now emits `L006` (unknown keyword) with a suggestion when an unknown identifier appears in the document body (was `P001` with no suggestion).

- Recorded DECISION-001: diagnostic codes keep stable category prefixes (`L/P/C/S/T` + 3 digits) rather than the task doc's literal `RXXX` example; spec §2.4 only requires stable codes and 33 call sites already use category codes.
