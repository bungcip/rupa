# Handoff — TASK-057: Migrate AST and parser to file-as-document

## Task ID

TASK-057 (Milestone 9 — Document Model & Root Layer Refactor)

## Completed Work

- Removed the `document "Name"` wrapper from the parser and `Document.name`.
- `Parser::parse` now always returns one file-level `Document`.
- File-level settings parse in any order: `size`, `background`, `seed`, `export`.
- Added stable diagnostics:
  - `P004` removed `document` declaration (with unindent help)
  - `C009` duplicate document `size`
  - `C010` duplicate `background`
  - `C011` duplicate `seed`
  - `C012` duplicate `export`
- The removed wrapper is consumed as a unit so authors get one migration error,
  not a cascade.
- Updated `format_source` to reject the legacy wrapper with `P004`; new
  file-level source formats idempotently.
- Updated `parse_source`, document validation help text, and compiler docs.
- Migrated examples, benchmarks, `docs/language-reference.json`, and all Rust
  test source strings/fixtures to file-level syntax to keep CI green.
  - `docs/language-reference.json` version is now `0.2.0` with a
    `document_model` section.
- Added parser tests for file-level settings, duplicate codes, and migration;
  added formatter tests.
