# Handoff — TASK-024: Cycle detection for layer references

**Date**: 2026-11-10T20:15:00Z
**Task**: TASK-024
**Status**: Completed and verified

## Implementation Summary

- **Diagnostic code**: `S021` (`RECURSIVE_LAYER_REFERENCE`) added with a
  stability assertion in the diagnostic tests.
- **Graph**: one node per layer definition, one edge per nested `place`.
  Root-level placements are not edges because the root cannot be referenced.
- **Algorithm**: deterministic depth-first search in source order with
  `Visiting`/`Done` marks. `LayerValidator::validate_cycles` is integrated into
  `validate_layers`, so `check`, compilation, and rendering reject cycles
  before lowering.
- **Diagnostics**: one `S021` per back edge at the placement that closes the
  cycle, with the path in the message (for example
  ``recursive layer reference: `A` -> `B` -> `A` ``) and help text. Unknown
  targets are skipped to avoid cascading from `S019`.
- **Coverage**: uninstantiated cyclic definitions are also rejected.
- **Decision**: `docs/decisions/DECISION-021.md` records the graph model,
  algorithm, multiplicity, and retained renderer guard.
- **Task document**: `agent/tasks/TASK-024.md` created before implementation.
